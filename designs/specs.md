# Specs UI - Calendario + Kanban

Herramienta: Figma (simulada)
Empleado: Fede
Tarea T1

## Pantallas

### 1. Calendario mensual
- Grid 7 columnas
- Header mes + nav prev/next
- Día seleccionado highlight
- Mini tasks count por día
- Responsive: colapsa a lista en mobile

### 2. Calendario semanal
- 7 columnas día, 24h slots
- Drag & drop tasks
- Resaltar hoy
- Breakpoints: tablet 2 cols, mobile stacked

### 3. Kanban por día
Columnas: Todo / In Progress / Done
- Card: título, hora, color prioridad
- Drag entre columnas
- Quick add
- Empty state

### 4. Flujo compartir
- Modal: link / email
- Permisos: vista / edita
- Lista colaboradores
- Revocar acceso

### 5. Responsive
- Mobile 375px
- Tablet 768px
- Desktop 1440px
- Navegación bottom bar mobile, sidebar desktop

## Decisiones
- Diseño wireframe low-fidelity
- Componentes reutilizables
- Export PNG para Beto
